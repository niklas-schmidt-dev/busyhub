# Bounce

A pixel ball with a fading trail that bounces around the front screen.

| Control | Does |
| --- | --- |
| Wheel | Speed, 1 to 5 pixels per frame |
| OK | Next color |
| Start | Pause and resume |
| Back | Quit |

**Settings:** ball color, start speed.

Runs on the bar or on your computer. It draws about eight frames a second, one HTTP request each, so it is a handy check of how fast your bar answers over Wi-Fi.
